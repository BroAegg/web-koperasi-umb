Server Won't Start:
  → Check if port 3000 is free: sudo lsof -ti:3000
  → Kill process: sudo lsof -ti:3000 | xargs kill -9
  → Restart: npm run dev

Login Failed:
  → Check database: http://localhost/phpmyadmin
  → Re-seed users: npx tsx prisma/seed-auth.ts
  → Clear browser cache (Ctrl+Shift+Delete)

Database Error:
  → Check MySQL running: sudo /opt/lampp/lampp status
  → Restart MySQL: sudo /opt/lampp/lampp restart
  → Check .env.local DATABASE_URL

Page Error:
  → Check terminal for errors
  → Clear cache: rm -rf .next
  → Restart: npm run dev
